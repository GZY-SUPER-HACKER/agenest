# Contributing

Thanks for taking a look. This is a small project with a few strong opinions; the fastest
way to get a change merged is to respect them.

## Getting a working copy

```bash
git clone https://github.com/<owner>/agenest.git
cd agenest
cp .env.example .env          # add a provider key if you want the Agent tab
./dev.sh start                # backend :8780, frontend :5173
```

`./dev.sh` creates the venv, installs Python and Node deps, generates local tokens under
`backend/data/`, and never touches any deployed instance. Open **:5173** — Vite proxies
`/api` to the backend.

Requirements: Python 3.11+, Node 18+ (the Agent tab's default `native` backend additionally
needs `npm i -g @earendil-works/pi-coding-agent` and a provider key).

## Tests

```bash
cd backend && .venv/Scripts/python -m pytest      # Windows
cd backend && .venv/bin/python -m pytest          # Linux/macOS

cd frontend && npm run build
cd frontend && npm run check:rail
```

The suite needs no network, no API key and no model: Pi and nanobot are stubbed inside the
tests. CI runs the same commands on Linux.

## What gets merged

- **Match the surrounding code.** Comments explain *why*, usually by naming the failure being
  prevented. A what-comment is noise; a why-comment is the documentation.
- **Tests assert the contract, not the layout.** Snapshot baselines are regenerated by
  deliberately changing a rule, never by re-recording current behaviour.
- **A rejected obvious option gets a design entry.** If you choose the non-obvious path, add a
  numbered section to [docs/design.md](docs/design.md) with the reason. If a decision is not
  written down, this project treats it as not yet made.
- **Keep third-party code out of the tree.** The agent backends speak documented protocols;
  adapt around them instead of vendoring them.
- **No new runtime dependencies** on the frontend (React is the only one) and none at all for
  `sdk/cpctl` and `sdk/csd-agent`.
- **Secrets never enter the repo.** Tokens live in `backend/data/` (ignored) or
  `/etc/csd/csd.env` (never copied). Local databases and Pi transcripts are ignored too.

## Adding an agent backend

Drop a module into `backend/app/agent/backends/` that defines `BACKEND_NAME` and implements
`AgentBackend`; the registry finds it by scanning that package. Add a `BACKEND_ONBOARD` dict if
the agent can open its own door, and tests for the wire translation. Nothing in the core should
need to name the new agent.

## Reporting bugs

Open an issue with the command you ran, the expected and actual behaviour, and the relevant
lines from `./dev.sh logs`. For anything security-sensitive, follow [SECURITY.md](SECURITY.md)
instead of opening a public issue.
